For Day 46, I'm continuing my **StudentHub Cloud Platform** project, where my goal is to build an AWS infrastructure foundation and gradually integrate it with DevOps tools and practices.

Instead of learning cloud services individually, I want to understand how they work together to support a real application.

# What is StudentHub?

StudentHub is my hands-on cloud infrastructure project, designed to help me develop practical experience with AWS networking, identity and access management, compute, storage, monitoring, and infrastructure automation.

My goal is to build the infrastructure step by step, document my progress, and eventually integrate DevOps practices into the project.

**<mark class="bg-yellow-200 dark:bg-yellow-500/30">Here's the roadmap I'm following:</mark>**

*   **Phase 1 — Network Foundation**  
    Setting up the VPC, public and private subnets, Internet Gateway, route tables, security groups, and network ACLs.
    
*   **Phase 2 — IAM and AWS CLI**  
    Configuring identity and access management, setting up AWS CLI access, and learning to interact with AWS resources from the terminal.
    
*   **Phase 3 — Compute with EC2**  
    Working with EC2 instances, connectivity, instance configuration, and IAM roles.
    
*   **Phase 4 — Storage and Content Delivery**  
    Exploring Amazon S3 and CloudFront for object storage and content delivery.
    
*   **Phase 5 — Containerization and Orchestration**  
    Working with Amazon ECR and ECS to understand container image storage and application deployment.
    
*   **Phase 6 — DNS and Domain Routing**  
    Exploring Amazon Route 53 and how DNS connects users to applications.
    
*   **Phase 7 — Serverless Computing**  
    Using AWS Lambda to understand event-driven and serverless execution.
    
*   **Phase 8 — Monitoring and Observability**  
    Setting up Amazon CloudWatch to explore metrics, logs, alarms, and infrastructure monitoring.
    
*   **Phase 9 — Infrastructure as Code**  
    Using AWS CloudFormation to define and manage infrastructure through templates.
    

### What's the bigger goal?

Once the core infrastructure is in place, I want to gradually integrate DevOps practices and tools such as Git, Docker, Jenkins, Terraform, and CI/CD pipelines.

The objective is not simply to deploy resources, but to understand how cloud infrastructure can be configured, managed, monitored, and automated.

I'll document each phase separately as I progress, including the configurations, challenges, troubleshooting steps, and lessons learned.

This is a learning project, so I'll share completed work as I finish each phase rather than treating the entire roadmap as already implemented.
